Logistics Data Analytics – Data Collection, Cleaning and Preprocessing

Project Overview

This project focuses on preparing logistics and supply chain data for analysis. It involves understanding the dataset, identifying data quality issues, cleaning the data, detecting outliers, and applying data preprocessing techniques.

Project Objectives

Understand the logistics dataset.

Inspect rows, columns, and data types.

Identify missing values and duplicate records.

Check invalid values and inconsistencies.

Detect and handle outliers.

Apply Min-Max normalization to numerical data.

Prepare a clean dataset for further analysis.

Dataset Information

Dataset Name: Dynamic Supply Chain Logistics Dataset

The dataset contains logistics-related information such as:

Vehicle GPS locations

Fuel consumption

Shipping costs

Delivery time and delays

Warehouse inventory

Traffic congestion

Weather conditions

Route risk information
